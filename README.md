# Maa Laxmi Steel — Screenshot-inspired prototype

Files:
- index.html
- style.css
- script.js
- assets/ (local demo product images cropped from the supplied screenshots)

Open `index.html` in a browser, or upload the whole folder to GitHub Pages.

The prototype includes:
- Home page
- Product catalog + search
- Product detail page
- Inquiry cart with quantity controls
- Custom requirement form
- WhatsApp inquiry button
- Responsive mobile/desktop layout
- LocalStorage cart persistence

Replace the demo cropped images in `assets/` with your original product photos for a production-quality result.
